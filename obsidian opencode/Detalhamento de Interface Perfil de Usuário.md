[[Principal]]
**Objetivo da IA:** A estrutura visual (HTML/CSS) desta interface já está definida. Sua tarefa é gerar **exclusivamente o script TypeScript (`.ts`) do componente Angular (`PerfilComponent`)**. Este componente é responsável por exibir os dados do usuário logado e gerenciar o histórico de doações cadastradas por ele, garantindo reatividade e código limpo. 

## 1. Gerenciamento de Estado e Tipagem * Crie propriedades fortemente tipadas para armazenar os dados do perfil (ex: `usuarioLogado: Usuario`) e a lista de itens doados por ele (ex: `minhasDoacoes: ItemDoacao[] = []`). * É proibido o uso do tipo `any`. A interface `ItemDoacao` deve prever propriedades para lidar com o que está no HTML (como `titulo`, `descricao` e `status` - Ativo/Inativo ou Disponível/Doado). 

## 2. Inicialização e Integração (Serviços) * Injete o `AuthService` e o `DoacaoService` no construtor. * Utilize o `ngOnInit()` para carregar os dados. O fluxo deve ser: recuperar o ID/dados do usuário logado via `AuthService` e, em seguida, usar esse ID para buscar o histórico de doações específicas desse usuário no `DoacaoService`. 

## 3. Lógica de Ações da Interface (Métodos) A interface possui botões de edição e exclusão que precisam ser implementados: * **`editarPerfil()` e `editarDoacao(idItem: number)`:** Implemente a lógica de roteamento (usando o `Router`) para direcionar o usuário para as telas de formulário correspondentes, passando os parâmetros necessários na URL. * **`excluirDoacao(idItem: number)`:** O fluxo deve chamar o método de deleção no `DoacaoService`. Em caso de sucesso na requisição HTTP, o método deve remover o item do array `minhasDoacoes` localmente, atualizando a interface instantaneamente sem necessitar de um novo *fetch* na API. 

## 4. Aplicação Estrita de Object Calisthenics Para manter o padrão da arquitetura, o script TypeScript deve respeitar estas regras: * **Proibição do `else`:** Utilize o padrão *Early Return*. Se a API retornar um erro ao tentar excluir uma doação ou buscar o histórico, capture o erro, atualize a variável de *feedback* da interface e retorne imediatamente. * **Um nível de indentação por método:** Mantenha os métodos curtos. Se a lógica para remover o item do array local após a exclusão for complexa, extraia isso para um método auxiliar privado (ex: `private removerItemDaLista(id: number)`).
