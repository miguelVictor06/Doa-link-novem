[[Principal]]
**Objetivo da IA:** O código HTML e CSS da interface de cadastro de doações já está definido, incluindo um *Drop Zone* para imagens. Sua tarefa é gerar **exclusivamente o script TypeScript (`.ts`) do componente Angular**, implementando a lógica de captura do arquivo, validação dos campos e envio dos dados para o back-end, mantendo as regras de código limpo. 

## 1. Gerenciamento de Formulário (Reactive Forms) * Utilize `FormGroup` e `FormBuilder` para gerenciar os inputs de texto (`itemName`, `condition`, `phone`, `description`). * **Regras de Validação:** Todos os campos devem ser obrigatórios (`Validators.required`). O campo de telefone deve prever uma validação básica de tamanho/formato. * Crie uma variável de classe (ex: `arquivoFoto: File | null = null`) para armazenar fisicamente a imagem selecionada pelo usuário antes do envio. 

## 2. Manipulação de Arquivo (Image Upload Area) * Crie os métodos para lidar com o input de arquivo (`fileInput`) e com os eventos de *Drag and Drop* do HTML (`dropZone`). * Implemente o método `onFileSelected(event: any)` para capturar o arquivo, validar se é realmente uma imagem (JPEG/PNG) e se respeita o limite de 5MB. Se for inválido, use *Early Return* e atualize uma variável de erro. * (Opcional para a IA, mas recomendado): Crie uma lógica simples para gerar uma *preview* da imagem no HTML após a seleção, substituindo o ícone de câmera. 

## 3. Submissão e Integração (DoacaoService) * Injete o `DoacaoService`, o `AuthService` (para pegar o ID de quem está doando) e o `Router`. * No método `onSubmit()`, verifique se o formulário é válido e se a `arquivoFoto` não é nula. * **Atenção Crítica:** Como há envio de arquivo, o payload não pode ser um JSON comum. Instancie um objeto `FormData`, faça o *append* do arquivo de imagem e faça o *append* dos valores do formulário (nome, condição, telefone, descrição, id do doador). * Chame o método de cadastro no `DoacaoService`. Em caso de sucesso, redirecione o usuário para a rota `'/hub'` ou `'/perfil'`. 

## 4. Aplicação Estrita de Object Calisthenics Para manter a arquitetura padronizada: * **Proibição do `else`:** Aplique a regra do *Early Return* no `onSubmit()` e na validação do arquivo. Se faltar a imagem ou o formulário for inválido, retorne imediatamente e não execute o resto do método. * **Um nível de indentação por método:** Se a montagem do `FormData` ficar muito longa, extraia essa lógica para um método auxiliar privado (ex: `private construirFormData(): FormData`).
